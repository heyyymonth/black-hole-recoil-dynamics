# ENNN: experiment title

**Researcher:** author name

**Model and applicable regime:** specify geometry, potential, dynamics, and omissions.

**Data provenance:** generated or observed; name the exact configuration or public release.

## Physical question and relevance

State one testable question. Cite the primary work that makes this calculation
relevant and distinguish reproduction, approximation testing, and new predictions.

## Method

Define equations, units, conventions, inputs, numerical methods, tolerances, and
comparison models. Explain the independent validation criterion.

## Results

Report executed results with links to tables, figures, and provenance. Define
columns and units. Separate numerical error from physical-model uncertainty.

## Verification and limitations

Record the actual checks performed, their outcomes, and the regime they cover.
State which conclusions the experiment supports and which remain untested.

## Reproduction

Give the source version, dependency installation, exact run and verification
commands, and expected output locations. Include seeds for stochastic calculations.
